# 功能与操作

以下说明对应已同步的 v1.06 源码；首次运行需配置自己的店铺、数据来源和通知对象。

| 功能 | 用途与边界 |
| --- | --- |
| 库存监控 | 查看重点产品的 ERP 库存、待入、阈值和提醒记录 |
| 抖店库存 | 按店铺采集官方导出，筛选整机 SKU，查看库存变化 |
| 补库存建议 | 对照主机维护表与 ERP 配件库存，识别可补库存配置 |
| 在线明细 | 同步程序负责的字段，保留人工处理状态和备注 |
| 通知机器人 | 按已启用机器人和配置的群发送提醒 |
| ERP 价格监控 | 根据配置监测价格与成本相关变化 |
| 钉钉监听与货源汇报 | 按需监听指定来源并生成日报、周报 |
| 清空缓存 | 先预览再确认，将可清理文件移入回收站 |

## 巡检与暂停（本机 v1.06）

“查看店铺”只切换展示；“参与巡检”勾选决定操作范围。顶部显示“监控中”时，点击“暂停监控”暂停所选店铺定时任务；显示“已暂停”时点击“启动监控”恢复。混合状态显示正在监控的店铺数。

侧栏“立即检查所有”触发 ERP 与抖店检查；两个库存页面右上角的“立即检查”仅触发对应模块。定时暂停与手动检查是不同操作。正在执行的后台步骤可能需要结束后才完成暂停。

抖店采集成功后关闭本工具对应的专属浏览器窗口；保留登录目录。失败时保留现场供排查。巡检失败不覆盖成零库存。

## 缓存与原始表格（本机 v1.06）

清空缓存包括有归档凭据的历史下载表格。保留每店当前原始表格、最新归档和关联下载、正在下载的文件、库存快照、人工记录和备注。预览不执行删除，确认后文件进入回收站；被修改或失去匹配凭据的文件不强制清理。

## 常见状态

- 等待报表：官方导出尚未完成，不表示已采集成功。
- 库存未知 / ERP 待核对：先检查数据来源与配件匹配，不能直接作为缺货处理。
- 在线明细尚未同步：先在本地查看清单，检查本店同步结果；不要重复创建整表覆盖人工记录。
- 群未收到通知：核对机器人启用状态、目标群、提醒条件及投递记录；仅成功排队不能证明群已收到。

## 验证范围

本机版本经过本地测试及打包检查；真实店铺、在线明细与群消息的验证应分别记录日期和结果。本文不替代每次发布验收，也不代表其他电脑或所有 Windows 版本均已验证。
