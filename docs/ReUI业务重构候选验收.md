# ReUI 业务重构候选验收（2026-11-07）

本轮替换此前原生嵌入方案。七个业务模块、21 个分区均由 React/ReUI 渲染，默认启动不构造 Tk 业务页面。软件更新仍在左下角，业务功能在右侧显示，图标沿用同一资源。只准备本地候选和 Git 提交，不推送、发布、改更新通道或替换现用程序。

## 功能对应

| 业务模块 | 保留的操作 | 新入口 |
| --- | --- | --- |
| 管理监控商品 | 新增/编辑、分类阈值、提醒类型、仓库、ERP 搜索、批量移除、Excel/CSV 导入预览/修订/确认、模板、逐商品检查覆盖 | 关注产品 / 搜索 ERP 商品 / 本轮检查明细 |
| 库存提醒记录 | 类型、时间、仓库和关键词过滤；详情、消息预览、库存快照导出 | 库存提醒记录 |
| 连接与通知 | SQL/脚本来源、周期、目录刷新、自动重登、Webhook/企业机器人、群检索、启停/移除、回执、缓存预览与回收站清理 | 库存数据来源 / 通知机器人 / 本地缓存 |
| ERP 价格 | 快照预览与绑定、解除、定时/立即检测、通知范围预览、涨跌与关联配置 | 价格监控配置 / 检测结果 |
| 货源汇报 | 周报日期、生成、正文编辑保存/下载、审阅发送、日报时段、AI 配置/测试、接收机器人 | 货源周报 / 定时日报 / AI 接入 / 接收机器人 |
| 钉钉监控 | 登录、账号选择、群和人员解析/候选选择、来源编辑、保存、启动/停止 | 消息监听 |
| 抖店库存 | 店铺添加/删除、巡检选择、启停/检查、独立浏览器或扩展、登录校验/基线、维护表检查、周期、ERP 配件、导出、库存变化、补库存预览/历史、在线明细、低库存规则、排除名单 | 整机库存 / 补库存提醒 / 库存变化 / 店铺管理 / 本店连接与维护表 / 低库存预警 / 人工排除链接 |

接口复用原领域服务、身份校验和导入事务，前端仅呈现用户字段。数据库密码、Webhook、AI Key 不回显；配置新密钥时使用密码输入。确认动作采用 AlertDialog；后台任务完成后刷新，任务 ID 可在页面切换后恢复。抖店排队设置收到实际落盘回执前持续忙碌，退出/更新保护不会因短暂等待结束而放行。
