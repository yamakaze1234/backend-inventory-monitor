# 维护表定时价格监控

## 使用入口

在 ERP 调价监控 → 价格监控配置中，选择“预览已有主机维护表”复用前台库存已保存的绑定，或“选择主机维护表”填写文件、工作表及 ERP 店铺编号。先查看范围和问题行，再确认绑定。切换原有 JSON 配置快照来源时需先解除旧绑定。

仅读取已保存的 xlsb/xlsx/xlsm 内容和公式缓存，不打开 Excel、不执行宏、不修改维护表。配件使用 ERP ID 精确查询公司大库库存成本，保留店铺/SPU/SKU、实际数量、固定附加配件及电源线规则。有身份、编号或数量问题时不采用部分范围；每轮重读失败则停止本轮查询，保留历史结果和错误说明。

## 每日巡检

“保存定时检测”支持北京时间 HH:MM，默认表单为 09:00，可填写多个逗号分隔的时间点。必须保存并开启后才启用；旧版间隔计划不会仅因查看页面而改变。程序需要运行，关闭期间不会执行；再次运行时若已错过保存的时间，只补查一次，然后回到下一固定时刻。

SQL 暂忙、连接异常或查询批次失败时，每 5 分钟补试，最多 3 次；之后保留失败说明，等下一个计划时间。手动“一键查看价格变动”不改变计划、不发送通知。

## 价格划分与通知

与配件工作台一致：上涨 ≥5%（包括从零上涨）、上涨 <5%、降价、未变化、首次采集、价格缺失。前价为零时不显示虚构百分比。按批次或前一日比较，展示前后成本、涨跌金额、涨跌幅及配置成本影响。

价格划分与通知阈值分开：原累计变动 100 元提醒保持不变，通知需明确选择机器人并启用；首次有效价格只建立基准。

补库存消息发送前强制同步并完整回读在线明细，确认对应同一清单后发送。同步失败或同步过程中清单变化时保存待发状态；下一次检查或手动恢复在线同步后继续。已成功或结果未知的发送不自动重复。

## 本轮验证范围

本轮制作隔离候选包，未替换现用程序、未推送发布，未进行真实钉钉发送和真实 ERP 成本巡检。源表只读检查：英特尔已保存表可完整提取 1893 套配置、496 个配件 ID；技嘉表存在 24 项编号/数量问题，预览阻止不完整绑定；第三店未验证。正式表未修改。

机器人接口说明见《机器人数据查询接口.md》；计划与涨跌分类均可通过只读接口查询。
