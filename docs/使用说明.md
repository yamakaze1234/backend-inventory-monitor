# 后台库存监控 v1.06 使用说明

## 启动与升级

已发布二进制以 Gitea 发行页附件为准。源码使用 `dev.ps1`，依赖与构建命令见 [开发与构建](开发与构建.md)。本次提交更新源码，未上传新版 Release 附件。

更新已安装程序时，先退出旧程序，把新 EXE 放到原安装目录，保留原有数据与配置，再更新快捷方式。关闭主窗口可能只收起到托盘。不要同时运行多个版本。

## ERP 库存

在设置中填写自己的 SQL Server 只读连接信息；公开源码不预填生产服务器。也可按库存说明使用浏览器采集脚本。添加关注产品，设置仓库、预警阈值与提醒机器人。未知库存与零库存分别显示。

## 抖店库存

1. 添加店铺并连接对应的专属浏览器，完成登录与店铺身份核验。
2. 配置主机维护表，核对工作表与店铺映射。
3. 勾选参与巡检的店铺，点击立即检查，等待官方导出及库存解析。
4. 通过“启动监控 / 暂停监控”控制勾选店铺的定时检查，旁边显示当前状态。
5. 查看补库存建议及 ERP 配件缺货原因；维护表或库存未知时先处理数据问题。

## 通知和在线明细

在机器人设置填写自己的连接并核对目标群，再启用。在线明细需单独配置对应表格。程序负责的库存字段可更新，人工处理状态和备注保留。排队、采集、同步和投递结果分别查看，不能用其中一步成功代替全部完成。

## 缓存

先预览范围再确认清理。历史表格需有归档凭据；每店当前原表、最新归档、正在下载的文件、库存快照与人工记录保留。文件只移入回收站。

## 可选功能

钉钉监听、货源日报周报和 ERP 价格监控按需配置。AI 汇报接口由用户提供，不是库存查询必需项。各功能与常见状态见 [功能与操作](功能与操作.md)。
