# 开发与构建

Windows、PowerShell 7、Python 3 与 Node.js 为开发环境。先安装依赖：

```powershell
python -m pip install -r requirements-build.txt
./dev.ps1 Check
./dev.ps1 Test
./dev.ps1 Build -OutputDirectory outputs/v1.06
./dev.ps1 Run
```

可通过 `-PythonExecutable` 指定 Python。DWS 默认位于用户目录 `.local/bin/dws.exe`；自定义位置使用 `tools/build_inventory_monitor.ps1 -DwsPath 路径 -OutputDirectory outputs/v1.06`。

产物名称为 `后台库存监控_v1.06.exe`。构建验证模块与资源完整性，生成 SHA-256 清单，不打包数据库或运行配置。分发时附带第三方许可。本次源码更新不等于已上传 Release 附件。

抖店配件 ERP 查询可能需要独立匹配工具；通过环境变量 `INVENTORY_MATCH_ROOT` 或程序配置提供其位置。该独立工具不并入本仓库。

发布前从当前源码运行测试并重新构建；不要拿历史验证文件充当本轮证据。源码启动产生的运行数据不提交。
