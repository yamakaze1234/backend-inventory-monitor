# 价格变动与机器人查询候选（2026-11-08）

本轮按最新要求改为一键查看价格变动。当前 ERP 账号的库存调价单接口返回权限错误，用户已取消该项；没有继续开权限、添加不可用入口或将成本检测记录冒充调价单。

## 已完成

- 左侧按截图排列：工作台为配件库存监控、订单巡检匹配、前台库存监控；业务管理为钉钉货源监控、ERP调价监控、库存提醒记录；设置为管理监控商品、连接与通知设置。软件更新仍在左下角。货源周报、定时日报、AI 接入和接收机器人保留在钉钉货源监控的分区中。
- ERP调价监控默认显示“查看价格变动”。一键执行现有 SQL 成本检测，展示前后成本、涨跌、关联配置和按实际 BOM 数量计算的每台成本变化。小于提醒阈值的涨跌也显示；首次采集、价格未知、历史数量缺失均明确保留未知。
- 支持历史批次和该批次与前一自然日最后有效采集的比较。只比较相同成本来源，不跨数据库/来源混用价格。历史成本影响使用当次保存的配置数量；列表筛选后金额明确标为筛选内配件的成本变化，不冒充整机总成本或利润。
- 手动查看不发送通知、不生成提醒任务、不消耗累计提醒锚点，也不修改原定时检查时间。原定时监控及通知配置保留。
- 26 类数据集提供字段白名单、筛选、时间范围、排序、完整分页及快照校验。只读查询令牌不能调用业务写入、匹配、配置保存或更新安装。独立的显式价格刷新接口只读取 ERP 并更新本地检测缓存；任务可轮询，不能查看其他业务任务。
- 接口目录、契约和标准库 CLI 已准备；详见 [机器人数据查询接口](机器人数据查询接口.md)。本轮没有部署新机器人或启用自动群提醒。
