# 部门通用候选

适用于同公司、同一套 ERP 的不同部门。本轮只提供候选包和本地源码，不更新现用程序、不推送发行。

## 部门首次配置

1. 将程序放入本部门独立安装目录。新安装默认使用当前 Windows 用户本地应用数据中的独立工作区，不自动带入原作者店铺、群、机器人或订单队列。设置 → 连接与通知设置 → 部门与工作区，可填写部门和工作区名称并查看数据目录。
2. 配置本公司 ERP 连接，在店铺管理中添加本部门店铺，并绑定相应维护表。库存仍按既有公司仓库业务口径读取。
3. 添加企业通知机器人只需群名称、机器人名称和通知类型。当前钉钉组织账号可唯一解析时自动填入标识；账号不明确、群或机器人重名时必须从实际查询结果选择。已有账号登录及群权限仍需具备。此入口仅配置通知，不自动创建机器人或加入群。
4. 订单巡检匹配 → 订单机器人设置，单独配置完整匹配项目、控制目录、独立运行数据目录、运行程序和允许的店铺。匹配项目须已有对应店铺维护表配置。兼容后端不是完整匹配项目安装器，依赖说明见 `../integrations/order_backend/README.md`。
5. 安装兼容后端需要原服务、队列和 Stream 连接器明确停止。界面先保存配置，再显式安装；安装备份旧文件，首次配置保持停止。接单机器人需要企业应用 Stream 能力，与库存、调价通知机器人分开配置。

## 缓存清理

连接与通知设置 → 本地缓存，可选择群聊消息缓存、已完成历史提醒、货源周报中间缓存、诊断日志、抖店历史导出。手动清理先预览再确认；计划可设置北京时间固定时刻、每隔多少天执行及保留天数，默认不开启。

清理只处理指定范围；文件进入回收站，配置、登录资料、数据库文件及未完成消息不纳入清理。运行中的业务会延后清理，失败记录可在页面查看。保存新计划后由该设置接管旧导出清理规则。

## 商品筛选

管理监控商品的顶部筛选统一作用于关注产品、ERP 商品目录和检查明细。支持名称关键字、完整 ERP 商品编号及综合搜索；重置筛选恢复全部列表，并显示匹配数量。

## 兼容及验证边界

原安装旁存在既有库存数据时继续使用原工作区；本轮没有迁移或修改现用数据。部门名称仅作标识，修改它不会移动数据。不同安装目录可区分工作区，但当前固定本地服务端口仍限制同一 Windows 主机同时运行一个实例。

候选通过隔离数据及无界面浏览器验证；未执行真实 ERP 写入、群发送或正式订单后端部署。正式使用前需要用目标部门账号检查连接和业务权限。
