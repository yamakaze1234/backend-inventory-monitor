# 部门订单机器人兼容层

此目录只包含源码，随候选程序打包到 `order_backend`。不包含登录资料、运行配置、维护表或队列。库存通知机器人与本目录的 Stream 订单机器人独立配置。

在设置中明确选择匹配项目根目录、控制项目目录、独立队列目录，以及 Python、DWS、PowerShell 7、Node 可执行文件。匹配项目仍需原有 `app/src` 业务核心、Python 依赖、ERP 连接，以及 `app/data/维护表设置.json` 中相应店铺的维护表配置；本兼容层不是完整匹配项目安装包，也不负责安装依赖或迁移 ERP 会话。

新部门应使用独立的匹配和控制源码安装目录。允许的店铺 ID 与名称只控制订单机器人任务范围，不能代替 ERP 店铺权限或维护表绑定。额外店铺必须先在匹配项目的维护表设置里完成配置；原后端会校验未配置的店铺，不能按名称推断配件。

保存设置不会部署或启动。点击部署前，用原程序停止订单服务并等待任务和消息回执确认；存在活跃心跳、启用状态、排队、未知写入或未知投递时会拒绝部署。旧版源文件中固定的队列目录也会检查。部署备份位于库存数据目录 `order-backend-backups`，失败时恢复原文件，新增文件移动到失败备份。不得将其他部门已绑定的后端重新指向本部门。

每次部署生成 `order-department.json` 指针，并为独立队列创建 `agent/.codex/config.toml`，仅注册 `erp_order_matching`。`ORDER_BOT_CONFIG` 贯穿控制器、工作进程、Stream 连接和 MCP 子进程；配置来源为当前库存数据目录下的 `order-bot.json`。没有个人绝对路径、预选群或店铺兜底。Windows 自动启动任务不自动创建或接管。

部署后按群与机器人名称查询，在当前钉钉组织中选择已发布、支持 Stream 且在目标群中的应用机器人。首次保存保持停止状态，再由用户启动。多个部门应使用不同 Stream 应用，不能同时争用同一机器人的消息入口。

本地验证仅使用合成文件、模拟运行器与只读 MCP 工具清单；真实 ERP 匹配、登录、群消息与跨部门实际部署仍需对应环境验收。

手动匹配和群通知默认使用网店单号，保留 A 或 A-1 后缀；合单通知列出对应的网店单号。明确输入 NO- 开头的 ERP 单号仍可查找，ERP 写入和回读始终使用核对过的内部单据标识。

## 日常未匹配巡检（2026-11-09）

日常巡检使用 ERP `pages/net/getNetOrderList.htm` 的 `b_match_goods=2`（未匹配）、`b_dispose=1`（待处理）和本店 `shopId`，不再调用已关联订单补查。订单明细兼容 `goods_id` / `product_goods_id`，部分匹配订单里已有有效关联的行直接跳过。空值或 0 的行才继续精确识别 SPU、SKU，按维护表新建或复用一致套餐并回读关联。

已匹配套餐不在日常巡检中复核或覆盖；配置变更使用明确的“重新匹配订单/SPU”入口，仍使用原授权计划、冲突保护和写后回读。巡检时间范围维持昨天零点至本次开始时间。安装更新不恢复已暂停的匹配服务。

自动匹配通知显示实际运行耗时、每店成功/待处理网店订单数及简短原因。同单多行去重，部分完成订单仅计待处理；历史任务缺少逐单回读时继续使用行数，不伪造订单数。日常未匹配筛选与人工重新匹配边界不变。


## 顺丰路由认证

发货监控支持顺丰开放平台生产路由查询 `EXP_RECE_SEARCH_ROUTES`，使用固定官方 HTTPS 地址与简易 MD5 签名。运行目录 `shipping-sf-auth.json` 设置 `provider: sf-open`、`environment: production`、`partnerId` 与 `checkWord`；实际凭据只保留在本机，不放入源码、安装包或日志。旧内网路由的 `apiKey` 配置仍兼容。

安装独立 `sf` 包的 Python 3.14/3.15 后端可设置 `provider: sf-sdk`，复用 `Sf(partnerID, checkWord).查询路由(number, checkPhoneNo=phone)`；接口权限、运单身份和实际节点的核验规则不变。包属于外部后端依赖，不随桌面 EXE 捆绑。

只读查询按运单号核验，ERP 手机号末四位真实可见时自动传入。空轨迹、运单不匹配、未来节点、查询或授权失败均不能证明揽收；全部包裹有真实揽收证据且删除前运单集合及在线订单身份再次核对一致，才沿用既有在线行删除流程。沙箱结果不能用于生产删行。生产权限未开通返回 `A1004`，需在顺丰开放平台开通对应接口，本机无法代替授权。

官方说明：[路由查询](https://open.sf-express.com/Api/ApiDetails?level3=397)、[认证规范](https://open.sf-express.com/developSupport/976720?activeIndex=641728&authId=1)。

## 自动巡检运行时段

订单自动巡检默认只在北京时间 18:30 至次日 00:00 启动。可在「设置 → 监控与巡检计划 → 订单自动巡检」修改。开始时间、结束时间和巡检间隔（分钟）一起保存，旧设置沿用原有间隔；修改后无需重新绑定机器人。每个时段开放后按设置的间隔巡检；到结束时间仍未开始的自动任务会取消，已开始的任务继续完成。原自动巡检暂停状态、手动匹配、手动巡检和发货监控不受时段限制。
